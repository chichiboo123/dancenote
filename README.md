# 동선노트 (Dongseon Note)

> 뮤지컬 연습 장면을 무대 평면도 위의 **동그란 이름표**로 옮겨 기록하는 교실용 웹앱

초등학교 뮤지컬 수업에서, 연습 사진을 찍으면 학생들이 무대 어디에 서 있었는지를
위에서 내려다본 무대 평면도에 옮겨 줍니다. 동선이 바뀔 때마다 컷을 쌓고,
컷을 이어 재생하면 동선이 움직이는 모습을 볼 수 있습니다.

- **사용자**: 초등 교사, 그리고 초등학생(3~6학년) 혼자서도 사용 가능
- **기기**: 태블릿(아이패드·갤럭시탭) 우선, 스마트폰·PC에서도 동작
- **서버 없음**: 모든 처리는 브라우저 안에서만 이루어집니다

## 🔒 개인정보 안내 (꼭 읽어 주세요)

- 사진과 이름은 **이 기기 안(브라우저 저장소)에만** 저장됩니다.
- 인터넷으로 어디에도 보내지 않고, 분석 도구(트래킹)도 넣지 않았습니다.
- **얼굴을 알아보지 않습니다.** 사람의 형태만 찾고, 이름은 사용자가 직접 붙입니다.
- 공연을 만들 때 "사진은 저장하지 않고 위치만 저장하기"를 켜면 원본 사진을
  남기지 않고 평면도 자리만 보관합니다.
- 기기에서 앱 자료를 지우면 되돌릴 수 없으니, 필요하면 JSON 백업을 내보내 두세요.

## 사용법

1. **새 공연 만들기** — 공연 이름과 무대 크기(가로·세로 m)를 정합니다.
   - 빠른 선택: **교실 앞**(6×4m) / **강당**(10×6m) / **큰 무대**(14×9m)
   - **사용자 지정** — 실제 공연장 크기를 알면 가로·세로를 0.1m 단위로 직접 적습니다. (1~60m)
   - 공연 정보를 고칠 때, 저장된 크기가 프리셋과 똑같으면 그 프리셋이, 아니면 사용자 지정이 골라진 채로
     열립니다. 프리셋을 고른 뒤 숫자를 손으로 고치면 사용자 지정으로 바뀝니다.
2. **친구 명단 넣기** — 한 명씩 넣거나, 엑셀에서 복사한 이름을 한 번에 붙여넣습니다.
   이름마다 서로 잘 구분되는 색이 자동으로 배정되고, 칩을 누르면 색·배역을 바꿀 수 있습니다.
3. **컷 기록하기** — 네 가지 방법이 있습니다.
   - **사진 찍기 / 사진 올리기** — 여러 장을 한 번에 고르면 고른 순서대로 컷이 됩니다.
   - **영상 올리기** — 영상을 보다가 장면을 골라 컷으로 만듭니다.
   - **사진 없이 짜기** — 사진 없이 평면도에 친구를 직접 놓아 동선을 미리 짭니다.
     (연습 전에 동선을 계획할 때 쓰세요)
4. **무대 영역 정하기** — 사진 위에서 무대 네 귀퉁이를
   ① 무대 뒤 왼쪽 → ② 무대 뒤 오른쪽 → ③ 무대 앞 오른쪽 → ④ 무대 앞 왼쪽 순서로 누릅니다.
   누르는 동안 돋보기가 떠서 정확하게 찍을 수 있고, 찍은 점은 끌어서 옮길 수 있습니다.
   다 정하면 사진의 아무 곳이나 눌러 평면도에서 같은 자리가 맞는지 확인할 수 있습니다.
   다음 컷부터는 이전 컷의 무대 영역을 그대로 물려받습니다.
5. **이름 붙이기** — 앱이 사진에서 사람 모양을 찾아 네모로 표시합니다.
   네모를 누르고 명단에서 이름을 고르면 됩니다.
   - **앱이 못 찾은 친구는 빠뜨리지 않습니다.** 화면 아래 **&lsquo;아직 자리를 안 정한 친구&rsquo;**
     칸에 남은 친구가 모두 나옵니다. 이름을 누른 다음, 사진이나 평면도에서 그 친구가 선 자리를 한 번
     누르면 들어갑니다. (사진이나 평면도의 빈 곳을 길게 눌러 넣는 방법도 그대로 됩니다)
   - `다시 찾기`를 눌러도 이미 붙여 둔 이름은 사라지지 않습니다.
   - 사람이 아닌 네모는 눌러서 **"사람 아니에요"** 로 지웁니다.
   - **사람 찾기 민감도** 슬라이더로 더 많이 찾을지 / 확실한 것만 찾을지 조절합니다.
   - 평면도의 동그란 이름표는 끌어서 자리를 고칠 수 있습니다.
     끌 때 줄이 맞는 자리에 **착 붙고**, 여러 명을 골라 **함께 옮길 수** 있습니다.
     (아래 [평면도에서 정확하게 놓기](#평면도에서-정확하게-놓기) 참고)
   - 지난 컷에서 그 근처에 있던 친구를 **"지난 컷 자리"** 로 추천해 줍니다.
   - 두 번째 컷부터는 **지난 컷처럼 이름 붙이기** 버튼 하나로, 지난 컷에서 가까이 있던 친구 이름을
     이름 없는 네모에 한꺼번에 붙입니다. (가장 가까운 짝부터 정하고, 너무 멀면 붙이지 않습니다)
   - 객석이나 무대 옆에 선 사람(선생님 등)은 **무대 밖**으로 보고 빼 둡니다. `무대 밖 n명 보기`로 다시 볼 수 있습니다.
   - 앞사람에게 다리가 가려진 친구는, 같은 사진 속 다른 친구들의 키를 보고 **발 위치를 짐작**해서
     평면도에 놓습니다. (사진에는 짐작한 발 위치까지 점선으로 이어서 보여 줍니다)
   - 사진 오른쪽 아래 **확대 버튼**으로 최대 3배까지 크게 보고, 손가락으로 밀어서 작은 친구를 누를 수 있습니다.
6. **컷 저장하기** — 저장하면 공연 화면으로 돌아갑니다. 같은 이름은 모든 컷에서 같은 색입니다.
   - 다음 컷이 있으면 저장 줄의 **다음 컷 ›** 버튼으로 저장하고 바로 다음 컷으로 넘어갑니다.
     (사진을 여러 장 올렸을 때 컷 목록을 오가지 않아도 됩니다)
   - 이름 붙이기 화면의 `뒤로`는 늘 **컷 목록(공연 화면)** 으로 돌아갑니다. 무대 네 귀퉁이를 다시 정하려면
     사진 칸의 `무대 영역 고치기`를 누릅니다.
   - 컷 아래의 **이어 만들기**(⧉) 버튼을 누르면 **그 컷의 자리를 그대로 가져온 새 컷**이 **바로 뒤에** 생깁니다.
     움직인 친구만 끌어서 옮기면 되니, 동선을 이어 짤 때 가장 빠릅니다.
   - 사진이 없는 컷(사진 없이 짜기, 사진을 저장하지 않는 공연)은 컷 목록에 **작은 평면도**로 보입니다.
7. **동선 재생** — 공연 화면의 `동선 재생`을 누르면 컷 1 → 2 → 3 순서로 친구들이 부드럽게 움직입니다.
   - 속도 **느리게 / 보통 / 빠르게**, **지나온 길**(궤적) 켜고 끄기, 재생 위치 슬라이더
   - 친구 이름을 누르면 **그 친구만 진하게**, 나머지는 흐리게 (한 번 더 누르면 모두 보기)
   - **반대쪽에서 보기** — 무대 위에서 객석을 바라본 모습으로 뒤집습니다.
     무대에 서서 연습시킬 때 왼쪽·오른쪽이 헷갈리지 않습니다. (설정은 모든 화면에 함께 적용되고 기억됩니다)
   - 컷 그림을 **끌어서 순서 바꾸기**, 연필 버튼으로 **컷 제목·메모** 적기
### 영상에서 컷 만들기

컷 기록하기 화면에서 **영상 올리기**를 고르면 연습 영상에서 장면을 골라 컷으로 만들 수 있습니다.

- **재생 / 멈춤**, **◀ 한 장면 / 한 장면 ▶**(한 프레임씩), **0.5배속**, 위치 슬라이더
- 원하는 순간에서 **이 장면 기록하기** → 그 화면이 컷이 됩니다
- 컷에 **영상 시각(타임스탬프)** 이 함께 저장되고, 아래 목록에서 누르면 영상의 그 시점으로 바로 갑니다
- **영상 파일 자체는 저장하지 않습니다.** 용량이 너무 커서, 파일 이름과 시각만 적어 둡니다.
  다음에 이 화면에 들어오면 지난번에 쓰던 파일 이름을 알려 주니 같은 파일을 골라 주세요.
- 열리지 않는 영상(아이폰 HEVC 등)이면 쉬운 안내가 나옵니다 —
  *설정 → 카메라 → 포맷 → '호환성 우선'*

8. **내보내기** — 평면도를 **PNG 그림**으로, 전체 컷을 **동선표 PDF**(한 장에 4컷 또는 6컷)로,
   공연 전체를 **JSON 백업 파일**로 저장할 수 있어요.

### 처음 쓰는 사람에게

- 앱을 처음 열면 **그림 안내 3장**이 나옵니다. (건너뛰기 가능)
- 첫 화면의 **사용법 보기**에서 7단계 설명을 다시 볼 수 있습니다. 초등학생이 혼자 읽고 따라 할 수
  있도록 짧은 문장과 쉬운 말로 적었습니다.
- 모든 화면 오른쪽 위의 **?** 버튼을 누르면 그 화면에서 할 일을 알려 줍니다.

### 앱처럼 설치하고 오프라인으로 쓰기

동선노트는 PWA입니다. 홈 화면에 추가하면 앱처럼 열리고, 인터넷이 없어도 동작합니다.

1. 첫 화면의 **오프라인 준비**를 눌러, 사람 찾기 파일(약 30MB)을 미리 받아 둡니다.
   (글꼴과 아이콘은 앱 안에 들어 있어서 따로 받지 않아도 됩니다)
   (와이파이가 잘 되는 곳에서 한 번만 하면 됩니다)
2. 홈 화면에 추가합니다.
   - 아이패드 사파리: **공유 → 홈 화면에 추가**
   - 안드로이드 크롬: **메뉴 → 앱 설치**
3. 비행기 모드에서도 사진 인식까지 그대로 동작합니다.

## 무대 평면도 보는 법

- 위쪽이 **무대 뒤**, 아래쪽이 **객석**입니다. (반대쪽에서 보기를 켜면 뒤집힙니다)
- 점선 격자는 무대를 아홉 구역으로 나눈 선입니다. (뒤·가운데·앞 × 왼쪽·가운데·오른쪽)
- 무대 **앞쪽 가장자리**에는 실제 무대 바닥에 테이프로 붙이는 것과 같은
  **센터 기준 번호**가 있습니다.

  ```
  4  3  2  1  0  1  2  3  4
              ↑
            센터(빨간 표시)
  ```

  센터에서 좌우로 같은 간격씩 떨어진 자리를 번호로 부르기 때문에,
  "지호는 왼쪽 2번으로 가" 처럼 말로 위치를 알려 줄 수 있습니다.
  친구를 직접 넣으면 `(왼 2)` 처럼 그 자리의 번호도 함께 알려 줍니다.

## 평면도에서 정확하게 놓기

이름 붙이기 화면의 무대 평면도에서는 PowerPoint·Figma처럼 이름표를 서로 맞춰 놓을 수 있습니다.
격자가 늘 보이는 것이 아니라, **끄는 동안 맞출 자리에 가까워졌을 때만** 분홍 맞춤선이 잠깐 나타납니다.

| 가까워진 곳 | 나타나는 것 | 붙는 자리 |
| --- | --- | --- |
| 다른 친구와 같은 앞뒤 줄 | 두 친구를 잇는 가로선 + **가로 거리(m)** | 그 친구의 y |
| 다른 친구와 같은 좌우 줄 | 두 친구를 잇는 세로선 + **앞뒤 거리(m)** | 그 친구의 x |
| 무대 가운데(좌우) | 무대를 가로지르는 세로 점선 + `무대 가운데` | x = 0.5 |
| 무대 가운데(앞뒤) | 무대를 가로지르는 가로 점선 + `무대 가운데` | y = 0.5 |
| 둘 다 | 두 점선 + `무대 한가운데` | (0.5, 0.5) |
| 무대 앞 번호의 반 칸 자리 | 무대 앞까지 짧은 점선 + `왼 2.5` 같은 자리 이름 | 센터 기준 0.5칸 단위 x |
| 무대 옆 앞뒤 번호의 반 칸 자리 | 무대 옆까지 짧은 점선 + `앞에서 1.5` 같은 자리 이름 | 무대 앞 기준 0.5칸 단위 y |

- **붙는 순서**: ① 다른 친구 → ② 무대 가운데 → ③ 무대 앞 번호. 화면에서 약 10px 안에 들어왔을 때만
  붙고(번호 자리는 촘촘해서 최대 6px), 그보다 멀면 손 가는 대로 자유롭게 놓입니다.
- **Alt**를 누른 채 끌면 붙지 않고 자유롭게 옮깁니다.
- **거리**는 공연에 저장된 무대 가로·세로 길이(사용자 지정 포함)로 계산해 0.1m 단위로 보여 줍니다.
  (가로 거리 = |x₁ − x₂| × 무대 가로, 앞뒤 거리 = |y₁ − y₂| × 무대 세로)
- 무대 앞 번호(`4 3 2 1 0 1 2 3 4`)는 그대로이고, 번호와 번호 사이 **반 칸 자리는 보이지 않는 붙는 점**입니다.
  번호와 붙는 점은 `src/lib/stageMarks.ts`의 같은 식(`markX`)으로 계산하므로 서로 어긋나지 않습니다.

### 여러 친구 함께 옮기기

| 하는 일 | 결과 |
| --- | --- |
| 이름표 누르기 | 그 친구만 고름 (이미 혼자 골라 둔 친구를 한 번 더 누르면 이름 바꾸기) |
| **Ctrl**(맥은 **⌘**) + 이름표 누르기 | 고른 목록에 넣기 / 이미 있으면 빼기 |
| (태블릿) 이름표 누르기 → **여러 명 고르기** 켜기 → 다른 이름표 누르기 | Ctrl 없이 넣기 / 빼기 |
| 빈 바닥에서 **끌어 네모 그리기** | 네모 안의 친구 모두 고르기 (Ctrl·⌘·여러 명 고르기를 켜면 기존 선택에 더하기) |
| 빈 무대 누르기 · **Esc** | 모두 풀기 |
| 고른 친구 중 한 명 끌기 | 고른 친구 모두가 **같은 거리만큼** 함께 이동 (대형이 그대로) |

- 고른 친구는 이름표 바깥에 파란 테두리가 생기고, 평면도 아래에 `3명 선택` 처럼 보입니다.
  (그림으로 저장할 때는 테두리가 빠집니다)
- 함께 옮길 때 누군가 무대 끝에 닿으면 **모두 그 자리에서 멈춥니다.** 한 명씩 따로 가장자리에 붙이지 않으므로
  대형이 찌그러지지 않습니다.
- 함께 옮길 때도 **손으로 잡은 친구**를 기준으로 다른 친구·무대 가운데에 맞춰 붙습니다.
  같이 고른 친구끼리는 서로 맞춤 기준이 되지 않습니다.
- 반대쪽에서 보기를 켜도 끄는 방향은 화면 그대로 자연스럽고, 저장되는 자리는 늘 원래 무대 좌표입니다.
- 끄는 동안에는 화면만 바뀌고, 자동 저장이 손을 뗀 뒤 한 번에 저장합니다. 옮기기는 `되돌리기`로 되돌릴 수 있습니다.

### 이름표 크기와 모양

- **이름표 크기**: 평면도 아래 `작게 · 보통 · 크게` (이름 붙이기·동선 재생 화면에 함께 적용되고 기억됩니다)
- **이름표 모양**: 명단에서 친구 이름을 누르고 **모양 고르기**에서 🐰 👑 🌳 같은 이모지를 고르거나 직접 넣습니다.
  이모지를 고르면 동그라미 안에 이모지, 아래에 짧은 이름이 붙습니다. 동선표 PDF와 컷 목록 그림에도 같이 나옵니다.

### 무대 옆 앞뒤 번호

무대 왼쪽 가장자리에 **무대 앞 0 → 무대 뒤 4** 의 앞뒤 번호가 있습니다. (반대쪽에서 보기를 켜면 화면 오른쪽)
"앞에서 2번 줄"처럼 앞뒤 자리도 말로 알려 줄 수 있고, 끌 때 반 칸 단위로 붙습니다.

### 밖으로 꺼내기

- **평면도 → PNG 그림**: 이름 붙이기 화면과 동선 재생 화면의 `그림으로 저장` (2배 해상도)

- **백업 불러오기**: 첫 화면의 `백업 파일 불러오기` — 기존 공연을 덮어쓰지 않고 새 공연으로 들어갑니다.

  브라우저가 있어서, 다시 불러오지 못하는 일을 막기 위해서입니다.
  공연 이름은 파일 **안에** 그대로 들어 있어 불러오면 한글 제목이 그대로 나옵니다.

## 화면 크기

- **태블릿 가로**(900px 이상): 사진과 무대 평면도가 좌우로 나란히 보입니다.
- **태블릿 세로 · 스마트폰**: `사진` / `무대 평면도` 탭으로 바꿔 봅니다.
- 폰(520px 이하)에서는 큰 버튼이 가로로 눕고, 조작 버튼이 두 칸씩 나뉘며,
  대화상자 버튼이 위아래로 쌓입니다. 390px 화면에서 **가로 스크롤이 생기지 않는 것**을 확인했습니다.
- 한국어가 어절 중간에서 끊기지 않도록 `word-break: keep-all`을 적용했습니다.

## 버튼 규칙 (KRDS 기준)

- **위계 3단계** — 주요(채움) / 보조(외곽선) / 조용한(연한 배경). 화면마다 주요 버튼은 하나만 둡니다.
- **크기** — 기본 56px, 주요 동작 72px, 보조 동작 48px, 최소 44px. 어린이 손가락 기준으로 KRDS
  권장치보다 크게 잡았습니다.
- **상태** — 기본 / 마우스 올림 / 누름 / **초점(3px 파란 테두리)** / **사용 못 함(회색조)** 을 모두
  정의했습니다.
- **배치** — 한 줄에 놓인 버튼은 남는 자리 없이 고르게 나눠 가지고, 줄이 바뀌어 하나만 남으면 그 줄을
  다 채웁니다. (좌측으로 쏠려 보이지 않게)
- 아이콘에는 항상 글자를 함께 두고, 한국어는 어절 단위로만 줄을 바꿉니다.

## 완성도를 위해 넣어 둔 것

- **화면이 하얗게 되지 않습니다.** 예상 못 한 문제가 나도 안내 화면과 `다시 열기` 버튼이 뜨고,
  저장된 공연은 그대로 남습니다.
- **세로로 찍은 사진**도 화면을 넘지 않게 높이를 맞춰 보여 줍니다.
- **되돌리기**가 명단 화면과 이름 붙이기 화면에 항상 보입니다.
- **이미 있는 이름**을 또 넣으려 하면 알려 주고 넣지 않습니다.
- **공연 화면 맨 위에 &lsquo;다음에 할 일&rsquo;** 이 지금 상태에 맞춰 하나만 뜹니다.
- **새 버전이 준비되면** 화면 아래에 알려 주고 한 번에 바꿀 수 있습니다.
- **키보드만으로도** 쓸 수 있습니다. 맨 앞에 `바로 본문으로 가기`가 있고, 대화상자 안에서 탭이
  밖으로 빠져나가지 않으며, ESC로 닫힙니다.
- **화면 낭독기**를 쓰면 평면도에 누가 어디 있는지(예: &ldquo;서준 — 왼 2, 무대 뒤&rdquo;) 읽어 줍니다.

## 개발 환경

### 글꼴에 대해

본문·제목 모두 **Pretendard GOV**(가변 글꼴, `pretendard-gov` 패키지)를 씁니다. 글꼴과 푸터 아이콘
(Material Icons Outlined, `material-icons` 패키지)을 **앱 안에 담아** 두기 때문에, 학교 방화벽이 CDN을
막거나 인터넷이 없어도 똑같이 보입니다. 글꼴은 글자 묶음별로 잘게 나뉘어 있어서 화면에 실제로 쓰인
글자의 조각만 받고, 한 번 받은 조각은 오프라인용으로 담아 둡니다.
캔버스(평면도·PDF)에서 쓰는 글꼴 이름은 `src/lib/canvasFont.ts` 한 곳에 모아 두었습니다.

### 사람 인식 파일에 대해

오프라인에서도 인식이 되도록 MediaPipe 파일을 앱 안에 담습니다.

- `public/models/efficientdet_lite2.tflite` (EfficientDet-Lite2 int8, 약 7.5MB) — 저장소에 들어 있습니다.
  예전에 쓰던 Lite0보다 정확도가 높고(MediaPipe 공개 수치로 mAP 약 26 → 34) 파일 크기는 거의 같습니다.
- `public/models/wasm/` (약 23MB) — 저장소에 넣지 않고, `npm install` 할 때
  `scripts/copy-mediapipe.mjs` 가 `node_modules` 에서 복사해 옵니다.
  SIMD를 지원하는 기기용과 옛 기기용 두 벌을 모두 담아 둡니다.

무대 사진은 뒷줄 친구들이 아주 작게 찍혀서, 사진을 통째로 한 번만 넣으면 잘 놓칩니다. 그래서
(`src/lib/detector.ts`)

1. 사진 전체를 한 번 살피고,
2. 정해 둔 **무대 영역 근처만 잘라 최대 4조각으로 나눠 크게** 한 번씩 더 살핀 뒤,
3. 겹친 네모를 하나로 합치고(여러 번 찾을수록 확신을 조금 올림), 몸 일부만 잡힌 네모와 조각 경계에서
   잘린 네모는 버립니다.
4. 발이 무대 영역 밖이면 무대 밖 사람으로 표시하고, 다리가 가려진 사람은 '발 높이 ↔ 키' 관계를
   같은 사진의 다른 사람들로 구해서 발 위치를 짐작합니다.

int8 모델은 그래픽 가속(GPU)에서 결과가 비어 버려서 늘 CPU로 돌립니다.
시험용 무대 사진(10명)에서 예전 방식은 기본 민감도에서 3~4명을 찾았고, 지금은 10명을 모두 찾습니다.
속도(헤드리스 크롬, GPU 없이 측정): 준비 후 사진 한 장당 약 1.2초. 사진을 고르는 동안 미리 준비시켜 둡니다.

```bash
npm install     # 처음 한 번 (MediaPipe wasm도 함께 복사됩니다)
npm run dev     # 개발 서버 (http://localhost:5173/)
npm run build   # 배포용 빌드
npm run preview # 빌드 결과 확인
npm run lint    # 문법 검사
```

`main` 브랜치에 푸시하면 GitHub Actions가 자동으로 빌드해 GitHub Pages에 올립니다
